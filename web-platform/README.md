# KisanSeva2 Web Portal 🌾

> **Smart India Hackathon 2020 (SIH-2020)**  
> **Problem Statement:** Lack of technological intervention in value addition of agricultural products produced by SHGs/FPGs.  
> **Target Region:** Uttarakhand, India  
> **Original Repository:** [KisanSeva2](https://github.com/shivamkumard107/KisanSeva2)  

---

## 🌟 Overview

**KisanSeva2 Web Portal** is a web recreation of the Smart India Hackathon 2020 Android mobile application. It brings technology-based interventions to Uttarakhand farmers for:
1. **Value Addition & Packaging** to agricultural produce.
2. **Direct Farm-to-Buyer Marketplace** removing exploitative middlemen.
3. **Computer Vision / AI Crop Quality Grading** (Elite, Premium, Classic).
4. **Almora Cluster Aggregation** for small-scale farmers (&lt; 500 Kg produce).
5. **Dynamic Buyer Price Negotiations** with instant counter-proposals.
6. **Order Delivery & Route Navigation Maps** (connecting hill farms to regional mandis).
7. **Farmer Earning Wallet** with instant IMPS/UPI bank transfers.
8. **Blockchain-backed Agricultural Loan Ledger** & Credit Scoring (up to ₹3 Lakhs at 7%).
9. **Soil Testing Labs Directory** for all Uttarakhand districts.
10. **Agricultural Advisory & Crop Production Manuals** (Wheat, Paddy, Arhar, Mango, Banana, Guava, Organic pest sprays, Termite matka traps).
11. **State Warehouses & Cold Storages Directory**.
12. **Logistics & Freight Trucking Network** (Rivigo, Truck Suvidha, Transin, BlackBuck, etc.).
13. **Local Weather Forecasts & Advisory**.
14. **Multilingual AI Kisan Mitra Voice Assistant** (English & Hindi).
15. **Side-by-Side Reference Showcase** displaying all 15 authentic screenshots (`ss1.png` to `ss15.png`).

## 🚀 How to Run

### Method 1: Instant Local Server (Recommended)
Open your terminal in this folder and run:
```bash
node server.js
```
or
```bash
npm start
```
The server will start at `http://localhost:3000` and automatically launch in your default web browser!

### Method 2: Direct File Open
You can also directly double-click or drag-and-drop `index.html` into Google Chrome, Microsoft Edge, Firefox, or any modern web browser.

## 📱 Dual View Experience

- **📱 Mobile App View:** Simulates the authentic Android phone experience with top status bar, Android material toolbar, navigation drawer, and bottom navigation bar (`Home`, `Info`, `Quality`, `Chat`, `Profile`).
- **💻 Desktop Portal Mode:** Expands into a responsive web application dashboard.
- **🌐 Language Switcher:** Instant one-click toggle between **English** and **हिंदी (Hindi)** matching the app's XML resource dictionaries.
