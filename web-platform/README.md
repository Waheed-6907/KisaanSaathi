# KisanSaathi Web Platform 🌾

> **HACK-X 2026** · **Team ForeverKnights**  
> **Problem Statement:** Elimination of intermediaries, subjective mandi quality exploitation, and freight costs for smallholder farmers.  
> **Target Region:** Telangana (Warangal, Medchal, Hyderabad, Secunderabad, Nizamabad)  

---

## 🌟 Overview

**KisanSaathi** is a technology-driven agricultural platform empowering farmers with:
1. **Direct Farm-to-Buyer Marketplace** removing exploitative middlemen (0% broker commission).
2. **Computer Vision / AI Crop Quality Grading** (Elite, Premium, Classic) with fair price estimation.
3. **Warangal Cluster Aggregation** pooling harvests under 500 Kg to reduce logistics freight costs by 38%.
4. **Dynamic Buyer Price Negotiation** with counter-offer desks in Hyderabad & Secunderabad.
5. **Leaflet GIS Transit Routing** connecting farms to Bowenpally and regional mandis.
6. **24-Hour Guaranteed Escrow Settlement** directly to bank accounts.
7. **Blockchain Credit Score & 4% Subsidized KCC Loan Ledger**.
8. **Soil Testing Labs Directory** covering all Telangana districts.
9. **State Warehouses & Cold Storages Directory** (Telangana State Warehousing Corporation).
10. **Bilingual AI Kisan Mitra Voice Assistant** (English & Hindi) powered by Web Speech Synthesis.

---

## 🚀 How to Run

### Method 1: Instant Local Server (Recommended)
Open your terminal in this directory (or the project root) and run:
```bash
npm start
# OR: node server.js
```
The server will start at `http://localhost:3000`.

### Method 2: Direct File Open
Open `index.html` directly in any modern web browser.
